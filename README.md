## Editing the website

- Edit text and sections in index.html.
- Edit presentation in styles.css.
- The browser icon is favicon.svg.

The site is plain HTML and CSS. It needs no installation, build step, server, or API keys. Changes pushed to the main branch are published by GitHub Pages from the repository root. Keep .nojekyll so GitHub serves the files as static content.

The adoption figure is user-reported: approximately 10% on April 1, 2026 to 95% by September 2026 among Cisco renewal sellers. Preserve the population, dates, and distinction between adoption and realized business impact.
